📞 SUPPORT & AIDE
════════════════════════════════════════════════════════════════════════════════

PROBLÈME?

Connecté refusé (Connection refused):
   → Vérifier que PostgreSQL est démarré
   → Vérifier que le backend est lancé (npm run dev)
   → Vérifier les credentials dans .env

Token invalide:
   → Vérifier JWT_SECRET dans .env
   → Vérifier format du token ("Bearer <token>")
   → Vérifier que le token n'a pas expiré

Port 3000 déjà utilisé:
   → Changer le PORT dans .env
   → Ou tuer le processus sur le port

Base de données non trouvée:
   → Exécuter: createdb mamacare_db
   → Vérifier DB_NAME dans .env

RESSOURCES:
   → Lire les fichiers documentation (.md)
   → Consulter les exemples cURL
   → Utiliser Postman pour tester les endpoints
   → Vérifier les logs (npm run dev affiche tout)
